# Как выложить три поста

Через API нельзя: VK не даёт загружать фотографии на стену ни токеном
сообщества, ни пользовательским (подробности в SKILL.md). Поэтому руками,
через **Отложенные записи** — сообщество → «Записи» → «Отложенные» → плюс.

Порядок слайдов важен: первый — хук, второй — суть, третий — вопрос.
Если перепутать, пост потеряет ритм.

| время | тема | картинки | текст |
| --- | --- | --- | --- |
| 09:00 | Сентябрьский жор щуки | `morning-1.jpg` `morning-2.jpg` `morning-3.jpg` | `тексты/09-00-щука.txt` |
| 16:00 | Окунь осенью: снасти | `day-1.jpg` `day-2.jpg` `day-3.jpg` | `тексты/16-00-окунь.txt` |
| 21:00 | Уха из окуня | `evening-1.jpg` `evening-2.jpg` `evening-3.jpg` | `тексты/21-00-уха.txt` |

## По шагам, один пост

1. Открыть текстовый файл, выделить всё, скопировать.
2. В ВК создать запись, вставить текст.
3. Прикрепить три фотографии **по порядку** — ВК держит тот порядок, в
   котором их добавили.
4. Поставить время, сохранить как отложенную.

Три минуты на пост. Все три ставятся за один присест, дальше ВК выложит
их сам.

## После публикации

Скажи мне, что посты ушли, — я допишу их в `POSTED.json`. Пока этого нет,
темы считаются неиспользованными, и следующая сессия может выбрать их
снова.
